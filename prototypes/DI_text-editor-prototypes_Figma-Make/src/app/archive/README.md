## Project Documentation

All active project documentation is maintained in the following locations:

### Current Documentation
- `/guidelines/Guidelines.md` - Development guidelines (v2.1)
- `/change-log/` - Centralized change log system tracking all implementation changes
- `/carbon-conversion.md` - Carbon component conversion reference
- Component-specific READMEs in `/components/*/README.md`

### Change Log System
The `/change-log/` directory contains comprehensive documentation of all architectural changes, feature implementations, and refactoring work completed on this project. This is the authoritative source for understanding the evolution of the codebase.

---

**Note:** Previous versions of this project generated temporary planning and reorganization documents in the root directory. These have been removed as they were redundant with the centralized change log system. All important information from those documents has been preserved in the change log entries.
