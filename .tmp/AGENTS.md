# Tasks & Sub-tasks

This is where temporary artifacts like playwrite images should be storred; It's also where images can be pulled from for PRs and what not.

.tmp/tasks structure
```
{Prototype}
    {YYYY-MM-DD_session_id}
        {YYYY-MM-DD_sub-task_id}
            {playwright}
            {...}

```

Skills and user requests can trigger clean up of temp task files generated in a chat session or from a sub agent. Clean up is always at the users discression.

Always verify before deleting temp files as they are not tracked.
